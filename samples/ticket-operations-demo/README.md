# 星桥工单中心

这是操作手册生成器的端到端测试项目。它使用 Node.js 标准库提供 Web 前端与 JSON API，不依赖外部服务或第三方 npm 包。

## 启动

```bash
npm start
```

默认访问地址：`http://127.0.0.1:3000`。可通过 `PORT` 环境变量修改端口。

## 可验证功能

1. 创建工单
2. 搜索工单
3. 筛选优先级
4. 更新工单状态
5. 分配负责人
6. 添加处理备注
7. 刷新运营统计

所有修改操作都会调用真实后端 API，并在页面顶部显示成功结果。服务重启后恢复内置测试数据，便于重复执行。

## 测试

```bash
npm test
```
